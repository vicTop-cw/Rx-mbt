## 2. 新增：`scripts/bench_baseline.sh` 与 C4 性能基线

### 设计（可重复、低噪声）
- 每个用例**先 warm（同一命令跑一次不计时）再计时**，减少编译/缓存首次噪声；
- 所有 moon 调用走 `scripts/with_moon_lock.sh`（多 lane 并行时不互相踩）；
- 自动判平台/修 PATH（Windows 前置真 node、WSL 净化 + `--target-dir _build/wsl`）；
- 输出 Markdown 表格 + 可选 `--json <path>`（机器可读，便于前后对比）；
- **不做判绿**：性能基线不是门禁（`exit 0` 只要跑完），避免把它当测试。

## 3. 新增：`scripts/check_determinism.sh`

### 做什么
1. `gen_conformance_vectors.py` 连跑 N 轮 → 要求 **sha256 逐字节一致**；
2. 互操作生产者连跑 N 轮 → **字段级 diff**，把 `/crypto/` 下的差异归为"预期的随机 IV/时间戳"，
   其余任何差异 → FAIL；
3. 打印跨平台复核指引（Windows/WSL 各跑一次，non-crypto 差异应为 0）。

### 实测
| 平台 | 结果 |
|---|---|
| Windows Git Bash | `gen` 2 轮同 sha `f22dda48…`；生产者 2 轮差异 5（全 crypto）/非 crypto **0** → **PASS** |
| WSL Ubuntu-22.04 | 同上 → **PASS** |
| 跨平台（Windows 产物 vs WSL 产物） | 差异 5（全 crypto）/非 crypto **0** → 跨平台字节级一致（非随机字段） |
